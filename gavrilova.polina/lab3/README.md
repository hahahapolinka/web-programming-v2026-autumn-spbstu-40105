# Лабораторная работа 3

## Задание

Вариант 33. Реализуйте функцию shuffleArray(arr), которая перемешивает элементы
массива в случайном порядке.

## Реализация

Массив перемешивается алгоритмом Фишера–Йетса
(см.[Тасование Фишера-Йетса](https://habr.com/ru/companies/timeweb/articles/845544/?ysclid=mu2vvmiek7940170714)):
обход с конца к началу, на каждом шаге случайный индекс из диапазона `[0, i]` и
обмен элементов. Алгоритм гарантирует равномерное распределение всех `n!`
перестановок за `O(n)`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
