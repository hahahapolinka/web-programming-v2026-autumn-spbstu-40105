# Лабораторная работа 4

## Задание

Вариант 33.

**4.1.** Создать класс `Product` с полями:

- `id` — уникальный идентификатор (число)
- `name` — название товара (строка)
- `categories` — массив категорий (строки)
- `price` — цена (число)

Реализовать методы:

- `addCategory(category)` — добавить категорию
- `removeCategory(category)` — удалить категорию
- геттер `categoryCount` — количество категорий

**4.2.** Дан массив товаров. Реализовать функции:

- группировка товаров по категориям
- уникальные категории
- группировка товаров по диапазонам цен
- товары, входящие в заданную категорию
- товары с ценой выше заданной

**4.3.** Реализовать пользовательский интерфейс:

- Карточки товаров: название, цена, список категорий
- Кнопки: «Добавить категорию», «Удалить категорию», «Добавить товар», «Удалить
  товар»
- Форма создания товара (ID, название, цена). Форма добавления категории.
- При любых изменениях автоматически обновлять интерфейс
- Все операции добавления/удаления выполнять асинхронно через `Promise` +
  `setTimeout()`
- Использовать `localStorage` для сохранения списка товаров при закрытии вкладки

## Реализация

### Модель (`model.js`)

Класс `Product` хранит четыре поля: `id`, `name`, `categories`, `price`. Метод
`addCategory` добавляет категорию в массив, если её ещё нет, `removeCategory`
удаляет через `filter`, геттер `categoryCount` возвращает длину массива
категорий.

Функции работы с коллекцией:

- `groupProductsByCategory(products)` — возвращает `Map`, где ключ — категория,
  значение — массив товаров этой категории.
- `getUniqueCategories(products)` — возвращает массив уникальных категорий,
  собранных через `Set`.
- `groupProductsByPriceRange(products)` — группирует товары по фиксированным
  диапазонам цен (`0–999`, `1000–4999`, `5000–9999`, `10000+`), возвращает
  объект.
- `findProductsByCategory(products, category)` — возвращает товары, у которых
  есть указанная категория.
- `findProductsAbovePrice(products, minPrice)` — возвращает товары с ценой
  строго выше указанной.

### Интерфейс (`main.js`)

Состояние приложения — массив `products`, синхронизированный с `localStorage`
(ключ `lab4_products`). При загрузке данные восстанавливаются через `JSON.parse`
и пересоздаются как экземпляры `Product`.

Рендеринг (`render`) выполняет три задачи: обновляет чекбоксы доступных
категорий, отрисовывает карточки товаров и сохраняет состояние в `localStorage`.
Каждая карточка содержит изображение-заглушку (inline SVG с первой буквой
названия), имя, цену, ID в формате четырёхзначного числа, список категорий с
кнопкой удаления каждой и кнопку удаления товара.

Обработчики событий:

- Форма добавления товара — читает поля, собирает категории из чекбоксов и
  текстового поля (без дубликатов через `Set`), проверяет уникальность ID,
  добавляет товар.
- Форма добавления категории — находит товар по ID, вызывает
  `product.addCategory(category)`.
- Делегирование кликов на контейнере карточек — обрабатывает удаление товара и
  удаление отдельной категории.

Асинхронность реализована через `await delay(300)`, где `delay` возвращает
`Promise` с `setTimeout`. Все мутации данных выполняются после задержки, что
имитирует работу с сервером.

Автогенерация ID: если поле ID оставлено пустым, используется `getNextId()` —
максимум существующих ID плюс один.

## Запуск

Откройте `index.html` в браузере.
