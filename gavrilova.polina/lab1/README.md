# Лабораторная работа 1

## Задание

Вариант 33. Создать три карточки товара. Каждая карточка должна быть
представлена div-блоком, содержащим:

- Изображение (размер 200px на 150px);
- Заголовок (шрифт Arial, размер 18px, жирный стиль);
- Описание (шрифт Arial, размер 14px). Карточки должны располагаться в одну
  строку (горизонтально) с отступом 20px между ними. Для всех элементов
  используйте padding: 10px.

## Реализация

Страница состоит из контейнера `<main>` с заголовком `<h1>` и тремя карточками
товара. Каждая карточка — это `<div class="card">`, содержащий изображение
(`<img>`), заголовок (`<h3>`) и описание (`<p>`).

**Основные CSS-решения:**

- **Расположение карточек:** `display: inline-block` выстраивает карточки в один
  горизонтальный ряд, `margin-right: 20px` задаёт отступ между ними.
- **Фиксированная высота:** у карточки задана `height`, что обеспечивает
  одинаковый размер всех трёх элементов.
- **Обрезка текста:** описание ограничено через `-webkit-line-clamp` — длинный
  текст скрывается с многоточием. Полный текст доступен во всплывающей подсказке
  (атрибут `title`).
- **Отступы:** `padding: 10px` внутри карточек, `margin-right: 20px` между ними.
- **Шрифты:** Arial, 18px bold для заголовков, 14px для описаний.

## Запуск

Откройте `index.html` в браузере.
