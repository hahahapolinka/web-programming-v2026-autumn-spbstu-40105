# Лабораторная работа 2

## Задание

Вариант 33. Реализовать функцию countVowels(str), которая возвращает количество
гласных букв (a, e, i, o, u) в строке без учёта регистра.

## Реализация

Посимвольный перебор входной строки через for...of с приведением каждого символа
к нижнему регистру и подсчётом вхождений в набор гласных "aeiou".

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
